# Documentation

The main `README.md` at the repository root covers setup, architecture, configuration and
deployment. The notes here go deeper on particular areas.

- `security.md`: how accounts, invitations, passwords, abuse limits and the content security
  policy work, and what to keep in mind when changing them.
- `guest-invitation.md`: the page a guest lands on, how it is laid out as one letter, and how
  the sealed envelope animation is built.
- `mcp.md`: API keys, and the MCP server that offers the planner as tools to agents; how
  tenancy is enforced on both.
- `whatsapp.md`: invitations by WhatsApp through a self-hosted bridge, how numbers and
  messages are handled, and why the bridge is unofficial.

User-facing instructions live in `guides/`.
